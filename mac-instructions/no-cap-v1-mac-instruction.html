Caps Lock Control Layer on macOS

Replicate the supplied AutoHotkey layer using Karabiner-Elements.

Result

ShortcutAction
Caps + J/I/K/LLeft / Up / Down / Right
Caps + V + J/I/K/LWord-style Left / Up / Down / Right (Option + Arrow)
Caps + BackspaceDelete previous word (Option + Delete)
Caps + S/E/D/FMove mouse Left / Up / Down / Right while held
Caps + SpaceLeft click
CapsDoes not activate Caps Lock
macOS uses Option + Arrow / Option + Delete for the usual word-navigation/deletion behavior, so these replace the Windows Ctrl shortcuts from the AHK script.

1. Install Karabiner-Elements
  1. Download Karabiner-Elements from https://karabiner-elements.pqrs.org/
  2. Open the .dmg, run the installer, and finish setup.
  3. Launch Karabiner-Elements.
  4. When macOS asks for permissions, allow the Karabiner components in System Settings → Privacy & Security. Also allow Accessibility and Input Monitoring access when prompted.
  5. Restart Karabiner-Elements if it asks you to.

You do not need AutoHotkey, Homebrew, Python, or another scripting runtime.

3. Test

Open TextEdit and verify:

  • Caps + J/I/K/L moves the cursor.
  • Caps + V + J/L moves by word.
  • Caps + Backspace deletes the previous word.
  • Caps + Space clicks.
  • Hold Caps + S/E/D/F to move the mouse.
  • Press Caps by itself: normal Caps Lock must not turn on.
  • Press V normally without Caps: it must still type v.

Increase 5 for faster movement or decrease it for slower movement. Re-save the rule afterward.

5. Troubleshooting

Caps Lock still toggles: check Karabiner's Complex Modifications rule is enabled and that Karabiner has Accessibility/Input Monitoring permissions.

Nothing works: open Karabiner-Elements → EventViewer and confirm the physical keys are being detected.

V stops typing normally: make sure caps_v is only being set when caps_layer is active; use the JSON above unchanged.

↑ Back to top

6. Startup

Karabiner-Elements runs in the background and can start automatically at login. Check System Settings → General → Login Items and ensure the Karabiner services are allowed.
